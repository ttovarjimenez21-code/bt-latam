# BT LATAM TEC simplificado en Python + CRUD

Versión simplificada para que sí funcione rápido.

## Incluye
- Flask
- SQLite automática
- Login y registro básicos
- CRUD real de productos
- Catálogo conectado a base de datos
- Front simplificado pero conservando estilos base

## Ejecutar
pip install -r requirements.txt
python app.py

Abrir:
http://127.0.0.1:5000/
